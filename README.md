1. Sends a correctly-framed `echo("Hello, RPC!")` method call
1. Parses the response
1. Prints the result

This teaches you the **core RPC pattern**: method invocation across the network, with automatic serialization/deserialization hidden from the caller.

## Background: Method Calls in RPC

Once a client knows where a service is (via the name server lookup), it can call methods on it:

1. **Serialize the call:** Package the method name, arguments, and options as bytes
2. **Send over TCP:** Ship those bytes to the server
3. **Receive response:** Read the server's reply
4. **Deserialize:** Unpack the response back into usable data (result or exception)
5. **Return to caller:** Pretend the call happened locally
